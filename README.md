# Прапор

Одиночная браузерная 2D idle-игра про оружейное убежище, коллекцию пушек и рейды диких. Проект инициализирован **через DevHub**, шаблон `game2d` (Phaser 3 + TypeScript + Vite + Bun).

## Играть и разрабатывать

```sh
bun install
bun run dev
```

DevHub запускает игру из основной папки `F:/code/prapor`, адрес — http://127.0.0.1:3020/. Временная worktree показывает уже интегрированную версию. Имя и порт сервиса описаны в `devhub.json`.

## Игровой цикл

1. Выбери сектор в «Рейдах». Дворы доступны сразу, первый выход занимает около 30 секунд.
2. Выдай дикому оружие, выбери тактику и снаряжение. Здоровье, бой, поиск, характер, броня, состояние ствола и радиорубка влияют на шанс возвращения.
3. Отправь бойца. Рейд тратит патроны и, в сложных секторах, разведданные. Несколько диких могут идти одновременно.
4. Получи рубли, припасы и оружие. Провал может привести к ранению, потере снаряжения или бойца.
5. Развивай помещения, ремонтируй стволы, ставь модули, нанимай людей и забирай награды цепочек контрактов.

16 видов оружия пяти редкостей, три типа модулей, шесть зон, цепочки контрактов, четыре помещения с пятью уровнями. Открытые образцы остаются в коллекции после продажи или потери. При полном складе добыча автоматически продаётся. Мастерская производит деньги, патроны и детали; медблок лечит; радиорубка приносит разведданные и увеличивает отряд. После потери всего отряда первый новый дикий приходит бесплатно со стартовым оружием.

## Постоянные маршруты и снаряжение

У каждого дикого можно включить автовыходы в выбранный сектор. Он повторяет маршрут, пока жив, вооружён и хватает припасов. Порог здоровья задаётся отдельно; при необходимости боец ждёт лечения в медблоке или производства патронов и разведданных. Сломанное или потерянное оружие требует твоего вмешательства. Автоматика не тратит деньги на ремонт, медикаменты или найм.

Повторные рейды продолжаются и без открытой вкладки: при возвращении движок последовательно рассчитывает до восьми часов событий. Риск сохраняется на каждом выходе, включая потерю бойца и снаряжения. «Остановить автовыходы» отменяет будущие отправления, а уже начатый рейд доходит до конца. Есть общая остановка всех маршрутов.

- **Осторожно** — дольше, меньше добычи и расхода, выше шанс возвращения и слабее последствия засады.
- **Сбалансированно** — обычные время, добыча и риск.
- **Напористо** — быстрее и богаче, но выше расход, риск и тяжесть ранений.

Броня и рюкзак улучшаются до третьего уровня за рубли и детали. Броня помогает вернуться и смягчает ранения; рюкзак повышает добычу. Снаряжение нельзя менять в активном рейде. Новая тактика действует со следующего выхода: параметры текущего рейда фиксируются при отправке. Карта показывает группы и стадии маршрута, журнал — события каждого завершённого выхода.

Прогресс сохраняется в этом браузере каждые пять секунд. Экспорт и импорт JSON — в настройках. Сохранения первой версии автоматически переходят на новую схему, сохраняя людей, оружие, деньги, задания и активные рейды; автовыходы в них изначально выключены. При смене порта или домена переноси прогресс экспортом. Неизвестную или повреждённую версию интерфейс не перезаписывает автоматически.

## Проверки и устройство

```sh
bun run check
bun run test
bun run build
bun run worktree status
```

- `src/game/data.ts` — оружие, зоны, характеры, контракты и баланс.
- `src/game/engine.ts` — экономика, риск, результаты, офлайн-расчёт и проверка сохранений; без зависимости от Phaser и браузера.
- `src/game/operations.ts` — тактики, свойства снаряжения и ограничения улучшений.
- `src/scene.ts` — процедурный изометрический бункер, дикие, карта и маркеры рейдов.
- `src/main.ts`, `src/style.css` — интерфейс, снаряжение, арсенал и сохранения.
- `test/engine.test.ts`, `test/operations.test.ts`, `test/server.test.ts` — повторная добыча, траты, сохранения, перенос первой версии, порядок автономных рейдов, часы и standalone production.

Это играбельный MVP 0.2. Аккаунты, серверная экономика, синхронизация устройств, звуки и финальная настройка баланса пока не реализованы. Manrope и IBM Plex Mono включены локально с лицензиями OFL; игра не требует внешних запросов.

## Production

```sh
bun run build
bun run start
```

Самостоятельный Bun-сервер раздаёт `dist`, `/health` и защитные заголовки. По умолчанию `0.0.0.0:3000`; настройки — `HOST` и `PORT`. Нужны только Bun, `dist`, `server.ts` и папка `server`. DevHub не требуется. CSP разрешает встроенные стили динамического интерфейса; скрипты и остальные ресурсы — только собственные.

```sh
docker build -t prapor .
docker run --rm -p 3000:3000 prapor
```

Проект в MVP с `remote: null`: изменения сохраняются в локальном `main`. Облачная публикация не настроена.
