# Second arsenal wave — material atlases A

Generated with the built-in imagegen tool. Original RGBA pixels and alpha retained unchanged. Every 4×2 atlas maps row-major to receiver, barrel, handguard, stock, magazine, optic, muzzle, foregrip. These are decorative surface textures clipped inside each actual installed native SVG module; physical geometry remains modular.
