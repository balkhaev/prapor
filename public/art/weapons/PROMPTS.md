Built-in imagegen output. Original transparent pixels retained. Each 4×2 atlas contains eight decorative material surface patches, mapped in row-major order to receiver, barrel, handguard, stock, magazine, optic, muzzle, foregrip. Native editable side-profile geometry supplies the physical outline, ports, feed, connections and selected variant. Generated paint is clipped per actual part, rather than using an assembled weapon thumbnail. The very same assembly is used for workbench, loose cards and carried weapon.
